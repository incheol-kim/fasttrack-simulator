# fasttrack simulator

* 목적
  * 놀이공원의 줄서기 패스트트랙(롯데월드의 매직패스와 같은 상품)으로 인해 패스트트랙 줄이 아닌 일반 줄에 선 사람이 기다리는 시간이 어떻게 달라지는지를 시뮬레이션을 통해 시각적으로 보여주고 차이를 구해서 비교한다.
* 상세
  * 놀이공원의 어트랙션은 1개만 존재
  * 일반 줄과 패스트트랙 줄을 별도로 운영
    * 패스트트랙은 최대탑승인원 중 정해진 일부 인원수까지만 가능.
    * 패스트트랙에 줄 선 인원이 패스트트랙 최대탑승인원에 미달하면 일반줄 인원을 더 탑승시켜서 최대탑승인원까지 빈틈없이 채우도록.
  * 개장시간, 폐장시간, 1일 입장객수, 1일 패스트트랙권 판매장수(항상 매진됨), 1회 탑승인원 수, 1회 가동시간(탑승, 실제 가동, 퇴장 후 정리까지 모두 포함. 즉 소요시간이 5분이면 한 시간에 12번 가동 가능), 탑승인원수 중 패스트트랙 최대허용인원 퍼센트, 피크타임 시간대, 피크타임시 일반 줄의 대략적인 최대 대기 시간 등은 파라미터로 변경할 수 있도록
    * 위 파라미터들로부터 적절한 의미를 가지는 '혼잡도'를 계산해서 보여주도록. 파라미터들 변경시 실시간으로 혼잡도도 변경됨
    * 최초에 적절한 (1회가동시간 3분, 피크타임 4시간, 최장대기시간 2시간 등) 파라미터들을 임의로 넣어서 보여줄 것
  * 롤러코스터 타이쿤 게임에서처럼 사람들이 줄 서 있다가 놀이기구에 탑승하는 모습이 비쥬얼하게 보여져야 함. 즉 줄에 있는 특정 사람이 점점 앞으로 가는 것을 알 수 있어야 함.
  * 시뮬레이션
    * 화면은 좌우로 분할
      * 1) 왼쪽화면: 패스트트랙 제도가 없는 경우
      * 2) 오른쪽화면: 패스트트랙 제도가 있는 경우
   * 사람들이 등장해서 줄을 선다. 이때 왼쪽과 오른쪽 화면은 서로 동일한 시각에 사람이 나타나서 줄을 서고, 단지 오른쪽화면의 경우는 이번에 나타난 사람이 패스트트랙권을 가진 사람인 경우 패스트트랙줄에 서고 아니면 일반줄에 서게 됨.
   * 사람이 언제 populate될지는 어느정도 랜덤하지만 피크타임 등의 조건을 만족하도록. 패스트트랙권을 가진 사람도 전체적으로 균일하게 분포되도록.
  * 계산
    * 각 사람은 하나의 객체. 등장시부터 탑승시작시까지의 소요시간값을 가지게 됨
    * 하루 시뮬레이션 완료 후 최소, 최대, 평균, 분산, 표준편차 등의 값을 계산해서 보여주어야 함. 하루전체에 대해, 피크타임에 대해, 피크타임이 아닌 시간들에 대해 각각.
  * 언어
    * 단일 html (javascript 포함) 로, 브라우저에 로딩해서 사용하거나 notion 페이지 안에서 돌아가도록 

  ## 추가사항

  * 줄을 블록 단위로 압축해서 보여줄 때, 이 블록의 패스트트랙 인원수와 일반인원수를 시각적으로 한눈에 알 수 있게 (사각형의 가로픽셀수가 20이라면 5% 단위로 올림해서 1px씩 세로선을 채우거나, 농도를 짙게 하거나 등등 쉽게 알 수 있는 방법으로) + 숫자라벨
  * 폐장 시각에 줄에 남은 손님 처리: "탑승 실패"로 별도 집계
    * 파라미터 입력시, 다른 파라미터들로부터 계산하여 대략 안전하게 모두 탑승가능한 일일 입장객수를 일일입장객수 입력란 근처에 미리 보여주도록
  * 배속 600x에서도 사람 점이 자연스럽게 보이려면 렌더 보간 시간 상수 조정 필요 -> 최적 조정값 찾아서 적용할 것
  * 패스트트랙권 사용 시간대 제한 옵션 (실제 매직패스는 시간대가 지정됨) : 현재는 적용하지 않음.
  * 모바일 가로화면 대응 여부: 일단 데스크톱 우선
